# Read original source materials

Prefer native page text and original embedded pictures when a page is dense, has tiny text, or contains overlapping pictures. Pictures extracted from this exact PDF page preserve source membership; original Word media may replace them only after exact pixel matching. Native PDF text is preserved directly, without generative rewriting.

Read each original picture independently with the shared ImageParts contract. Separate directly visible scene facts, literal text regions and explicit gaps. A photograph may contain both useful scene information and unreadable lettering. Never discard its supported independent scene facts solely because lettering is unreadable, and never hide essential diagram or chart labels behind a generic summary. Nearby captions are context, not source image evidence.

Both readers receive the original image without a prior answer or page caption. Agreement admits candidate blocks only; an independent source and actual delivery audit must verify every retained scene/text block and reject guessed content or missing dependencies. Uncertain regions remain visible gaps. No information belongs only in an observation.

For a form mixing labels, multi-column text and pictures, consider read_regions first so row and column relationships remain explicit. This tool cannot replace tables or cross-page blocks.

The controller reserves two reads per picture with one binary format split per reader: normally two model calls, at most six including failed parent responses, plus delivery audits. A format failure aborts the candidate, not the source's readability. Valid incomplete observations do not trigger format retries. Preserve shared call/time budgets and the prior accepted publication on any failure.
