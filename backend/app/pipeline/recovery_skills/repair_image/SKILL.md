# Recover one image without guessing lettering

Use this tool for an image whose scene and literal text need different treatment.
The executor selects the original source image and enforces page/block ownership.
For a two-axis positioning diagram with a unique measured crossing, the executor
uses a bounded geometry-assisted proposal: original-pixel axis lines, named-object
bounding boxes, axis-crossing extents and explicit arrow relationships. This may
correct an earlier blind observation; the old observation remains an immutable
parent, not a permanent source truth. The model cannot delete earlier relationship
IDs to pass. Measured lines and estimated object boxes are still observations:
both the actual image delivery and rebuilt source page require independent audit.
Unsupported diagrams and photos use the ordinary path below. A failed geometry
proposal retains the original output; it does not trigger repeated prose guesses.
Read visible scene facts separately from text regions; no document captions or old
model descriptions are evidence of lettering. Do not include inferred names,
quoted text, text-derived values or label-dependent meaning in visual facts.

An independent read uses the same original picture without the first answer.
Matching text merely admits a candidate for source audit. Any illegible,
disputed or missing region stays as an explicit gap with source coordinates.
A photo's independently meaningful scene facts can be retained beside a text gap.
A logo, diagram, table or chart with missing labels cannot be summarized as if
complete; preserve the unresolved dependency. Never rewrite unrelated page blocks.

The ordinary candidate and final delivery audits must verify retained content,
its context and reading order and account for declared gaps. Failure or budget
exhaustion cannot certify a candidate. Do not retry the same evidence/model strategy.

If a full-image response exceeds the contract, the executor may retry two disjoint source crops, retain the full image only as context, and map all coordinates back to the original. This is bounded by the existing document budget. Failure to return valid JSON remains a format error, not proof that the pixels are unreadable.

Judge information separately from text readability. A small logo, icon, photo or
chart can carry information without lettering. Only source-confirmed blank,
decorative or noise regions are non-informative; small or blurred is not enough.
After an image audit rejects content or retains gaps, the executor permits one local revision of at most
four failed regions. Inspect original pixels and source crops; return typed
text/graphic/mixed/no_information/uncertain patches with supplied evidence IDs.
The actual rebuilt documents and chunks require a new independent source audit.
If a partial result already passed, failed local improvement preserves it. Otherwise,
one separately audited subset may retain independent verified
facts and explicit region omissions. Required labels/units remain dependencies.
No new hard budget, repeated free-form guessing or self-certification is allowed.

If a failed region is already covered by a verified retained block at overlapping
source coordinates, cite covered_by instead of repeating its text or labeling it
empty. Ownership and dependency checks precede the new source audit. A malformed
patch gets at most one format repair within the same revision and shared budget.
